## 摘要
数据包络分析（DEA）是一种广泛使用的非参数方法，用于评估决策单元（DMU）的相对效率。然而，经典的Charnes-Cooper-Rhodes（CCR）模型常常缺乏区分能力，特别是当输入和输出变量的数量相对于DMU数量较大时。在这种条件下，许多DMU被评估为“CCR有效”，得分为1，这使得难以对顶尖表现者进行排序或区分。为了解决这一局限性，我们提出了一种新颖的最大边际DEA（MM-DEA）模型，该模型将“边际最大化”的概念——受机器学习中的结构风险最小化启发——直接融入效率测量框架。与传统的超效率模型类似，所提出的MM-DEA模型将目标DMU从用于评估其自身的参考集中排除；但与超效率模型不同，MM-DEA对目标DMU自身的得分施加了明确的上限，确保每个得分都保持在标准的[0,1]范围内，而不会可能超过1。我们在理论上证明了MM-DEA模型是CCR模型的广义扩展，当权衡参数α为零时，它退化为后者。此外，我们展示了MM-DEA的分数规划形式可以被严格地转化为线性规划（LP）问题，确保计算效率。在我们的数值实验中，MM-DEA对高维合成数据集产生了唯一排名，而CCR模型无法区分任何DMU。我们的结果表明，“边际”可作为管理韧性和竞争优势的关键指标。

## Abstract
Data Envelopment Analysis (DEA) is a widely used non-parametric method for evaluating the relative efficiency of decision-making units (DMUs). However, the classic Charnes-Cooper-Rhodes (CCR) model often suffers from a lack of discriminatory power, particularly when the number of input and output variables is large relative to the number of DMUs. Under such conditions, many DMUs are evaluated as "CCR-efficient" with a score of unity, making it difficult to rank or distinguish between top performers. To address this limitation, we propose a novel Maximum-Margin DEA (MM-DEA) model that integrates the concept of "margin maximization" -- inspired by structural risk minimization in machine learning -- directly into the efficiency measurement framework. Like the traditional super-efficiency model, the proposed MM-DEA model excludes the target DMU from the reference set used to evaluate it; unlike the super-efficiency model, however, MM-DEA imposes an explicit upper bound on the target DMU's own score, ensuring that every score remains within the standard $[0,1]$ range rather than potentially exceeding one. We theoretically demonstrate that the MM-DEA model is a generalized extension of the CCR model, reducing to the latter when the trade-off parameter $α$ is zero. Furthermore, we show that the fractional programming formulation of MM-DEA can be rigorously transformed into a linear programming (LP) problem, ensuring computational efficiency. In our numerical experiments, MM-DEA produced a unique ranking for a high-dimensional synthetic dataset on which the CCR model failed to discriminate among any of the DMUs. Our results suggest that the "margin" serves as a critical metric for managerial resilience and competitive advantage.

- **已有方案的不足**：
  - 传统超效率模型（Andersen & Petersen, 1993）虽可打破并列，但分数可超过 1，偏离了标准效率分数的 [0,1] 解释，且不包含 CCR 模型为其特例。
  - 其他改进方法（如 Mehrabian et al.）也各有缺陷。
- **论文定位**：提出一个新的统一框架——最大边际 DEA（Maximum-Margin DEA, MM-DEA），将机器学习的“边际最大化”思想直接融入 DEA 目标函数，在保持 CCR 分数语义的同时解决区分度不足的问题。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- 受支持向量机（SVM）中**结构风险最小化**（SRM）原则启发，将“效率”重新定义为不仅是到达前沿，更是相对于竞争 DMU 保持“安全边际”（safety margin）。
- 引入**权衡参数 α ≥ 0**，在追求目标 DMU 绝对效率与最大化其与竞争者的间隔之间取得平衡。
- 核心约束变化：将其他 DMU 的效率上限从 1 收紧为 **1 − t**（t 为边际），同时限制目标 DMU 自身效率 θo ≤ 1，从而既保留了 CCR 的 [0,1] 语义，又能通过边际 t 区分原本并列的有效单元。

### 2.2 模型公式与 LP 转换

初始为分数规划问题：

- 目标函数最大化 **θo + αt**；
- 约束：θo = (y_o^T v)/(x_o^T u)，θo ≤ 1，对所有 i ≠ o 有 (y_i^T v)/(x_i^T u) ≤ 1 − t，u, v ≥ 0，0 ≤ t ≤ 1。

**转化为线性规划（LP）的步骤**：

1. 按 CCR 惯例归一化 x_o^T u = 1。
2. 替换变量：t′ = 1 − t，从而非目标 DMU 的约束变为 y_i^T v ≤ x_i^T (t′u)。
3. 变量代换：u′ = t′u，消去目标函数中的常数项 α，最终得到标准 LP 形式：

   - 最大化 y_o^T v − αt′；
   - 约束：x_o^T u′ = t′，y_o^T v ≤ 1，y_i^T v ≤ x_i^T u′（i ≠ o），u′, v ≥ 0，0 ≤ t′ ≤ 1。

### 2.3 理论性质

- **分数范围保证**：MM-DEA 的最优值始终落在 [0, 1] 区间内，区别于超效率模型，保留标准效率语义。
- **Proposition 3.1（CCR 推广性）**：当 α = 0 时，MM-DEA 模型等价于标准 CCR 模型。论文通过分情形（t′ = 0 和 t′ > 0）证明最优解可取 t′ = 1，从而严格约化为 CCR。
- **对偶问题解释**：MM-DEA 的对偶问题与 CCR 对偶结构相似，但有三处关键区别：
  1. 排除目标 DMU（使用 X−o、Y−o），与超效率模型类似；
  2. 参考集只需达到目标 DMU 产出的 (1−τ) 倍而非全额，且当 t′* < 1 且 τ* > 0 时，该下界恰好等于 αt′*；
  3. 输入缩放上限受 α + γ 控制，α 越大允许参考集使用的输入资源越多，对应原问题中对边际的更大强调。
